- Create documentation and architecture diagram.
- Convert app to Next.js App Router.
- Add DynamoDB repository with local development fallback.
- Add worker package and contracts.

## Phase 2 - Core workflow

- Campaign creation.
- Parallel worker run.
- Prospect generation and fit scoring.
- Outreach draft creation.
- Approval and audit flow.

## Phase 3 - Production readiness

- Deploy to Vercel.
- Provision DynamoDB table.
- Verify database connectivity.
- Record a concise product walkthrough.
- Confirm production links, architecture diagram, and operational checks.

## Product walkthrough script

"Loopaal is a supervised AI revenue-ops agent for small B2B teams. I create a campaign, launch parallel co-workers, watch them write to DynamoDB, review a personalized outreach draft, approve it, and see a complete audit trail. The important part is not blind automation - it is a shippable automation layer with memory, approvals, and real database-backed operations."
